# Locale Feste Roma — tema WordPress

Questo tema incapsula il bundle pubblicato da Lovable e conserva l'interfaccia, i media e le route client-side del sito originale.

## Installazione

1. Copia la cartella `wp-content/themes/locale-feste-roma` in `wp-content/themes/` dell'installazione WordPress.
2. Dal pannello WordPress, attiva **Locale Feste Roma**.
3. In **Impostazioni → Permalink**, salva nuovamente le impostazioni per rigenerare le route di WordPress.
4. Crea pagine WordPress con gli slug pubblici (`festa-18-anni-roma`, `feste-private-roma`, `location-compleanni-roma`, `sala-feste-roma`, `blog`) per assicurare risposte HTTP corrette anche alle visite dirette.

Il tema contiene il bundle del backup FTP. Le modifiche editoriali sono ancora nel bundle React: una seconda fase potrà trasformare pagine e articoli in contenuti WordPress nativi e modificabili dal pannello.
